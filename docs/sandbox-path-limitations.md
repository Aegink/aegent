# 沙箱路径守卫 —— 已知边界清单（C7/D1，T-6-01）

> 本文件是 `src/sandbox/path-guard.ts` 头注释 LIMITATIONS 的**同源拷贝**，
> 代码侧载体是导出常量 `PATH_GUARD_LIMITATIONS`（两处同文，改一处须同步另一处）。
> 依据：T-6-01 风险栏"符号链接逃逸——P0 先 realpath 归一后判定（记录已知边界进 LIMITATIONS）"。
> 部署语义：守卫是**工具执行层的出口级硬拦**（策略链批准之后、真实 I/O 之前），越界写/不可验证目标一律拒绝。

## 清单（7 条）

1. 符号链接逃逸按 realpath 归一后判定（目标存在取真身、不存在取最近存在祖先）；创建符号链接需要特权的环境无法实测逃逸路径，用例仅在可创建时运行
2. bash 侧覆盖面 = T-5-14 B 档虚拟操作（> >> < 三种重定向）；fd 重定向（2>、&>）与 tee/dd/cp 参数式写不在守卫范围（C29 #5/#6），>&N 形式的 fd 复制目标按非文件跳过
3. bash 命令里反斜杠是转义符（实际写入路径与字面目标可能不同），Windows 上含反斜杠的写目标按不可验证拒绝——bash 里请用正斜杠
4. 含 $VAR/反引号/引号的写目标、cd 之后的相对路径、Windows 上无盘符的 POSIX 形式路径（/tmp/x）一律判为不可静态验证，fail-closed 拒绝执行
5. 读面 P0 不限（与 C46 聚合出口 read 不拦一致）；仅当显式配置 readRoots 时才启用读边界
6. 断言与 I/O 之间存在 TOCTOU 竞窗；单进程 + 写队列串行下已最小化，跨进程攻击者不在 P0 威胁模型
7. 内核自用存储（事件库、spill 落盘、日志）是装配面路径而非模型可控输入，不在守卫范围

## 强承诺与弱承诺

- **强承诺**：read/write/edit/bash 四个文件工具的模型可控路径必经守卫（类型上工厂必收守卫实例），越界写不落盘、不可验证写不执行。
- **弱承诺**：守卫只覆盖上述工具入口；对 bash 里不经过重定向的写手段（见清单第 2 条）与任意第三方子进程的自发行为，P0 不承诺管住（同 D3/D16 的弱承诺纪律：**不假装已管住**）。
