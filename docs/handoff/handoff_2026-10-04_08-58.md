## 关键认知（后续会话必读）
- **assistant/message 的 stream 在事件顶层**（e.stream），不在 message 里；UI 打字机此前恒拿空数组直接跳终态（本轮顺修）
- **内核 store 内存优先**：走查注库（直接 INSERT events）对 --session 的宿主**无效**（内存镜像遮蔽）；跨会话读才回源 SQLite——走查会话与宿主 --session 必须分离，经侧栏「最近会话」切换触发回源
- **busy 窗口造法**：settings 供应商需 defaultProvider+credentials（credentials-set op）齐全，否则 agent-child 装配跳过→echo provider 瞬回；黑洞 server（listen 后永不响应）可造稳定 busy 窗口验证停止钮/队列条
- IAB evaluate 是隔离 world：改 DOM 属性/挂 window 变量不落地到页面主 world——用 locator 操作真实 UI
- 排队 per-row 编辑/删除需内核队列 op 协议面（本轮记档不做）
