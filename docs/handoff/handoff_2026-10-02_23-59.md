## 附带修复（三真缺陷）

1. usableInInput 的 slice(0,-1) 负数陷阱——"Enter" 等无 "+" combo 误判带修饰键。
2. 捕获监听 stopPropagation→**stopImmediatePropagation**：window 同元素 target
   阶段按注册序执行（分发监听先注册先跑）——真实按键不受影响（target=元素，capture
   先跑），合成 dispatch 会穿透；存量隐患根治。
3. host 静态服务补 **Last-Modified validator**：no-cache 无 validator 时浏览器退化
   为直接用缓存副本（UI 改文件 reload 拿旧模块）——走查实测抓出，static-files.ts。
