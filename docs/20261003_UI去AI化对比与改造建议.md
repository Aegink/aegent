## ① 结论一句话

**Tabs**（tabs.tsx）——default 变体选中 = `data-active:bg-background + text-foreground`（未选中 60% 文字色无底色）；line 变体 = 底部 **2px 指示条**，文字透明度不变；唯一保留 3px ring 的组件（ring-ring/50）。

**Collapsible**（collapsible.tsx + ToolLayout.tsx:19）——高度动画 300ms ease-in-out + **内容延迟 300ms 卸载**（防 Radix closed 读高闪烁）；显式 `transition-none` 防 scrollbar-color 非合成动画。
