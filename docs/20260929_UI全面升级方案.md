# UI 全面升级方案（2026-09-29 用户裁决 · v2 细节规格版）

> **缘起**：用户实际走查判定"所有页面都很简陋"，指令"参考多个仓库全面升级 + 全面排查 + 写 UI 全面升级文档"；v2 按用户要求**深入参考仓源码提取尺寸/位置/形态细节**——色值、字号、圆角、内边距、行结构均落成规格表（来源见各表标注，全部 🔴 只学形态）。
> **约束回顾**：全局约束 3 = 零前端构建链（不引 React/Vite）。**v2 勘察发现**：ZCode 统计图表用 recharts 库、组件体系是 Tailwind v4 + shadcn；opencode 桌面设置是 SolidJS + 自家 ui 包——两家的"形态"可以零依赖复刻（CSS 变量 + 组件类 + SVG），但"交互深度"（recharts tooltip 等）在方案 A 下按简化形态实现，详见 §5 路线裁决。
> **红线不变**：参考仓 UI 全部 🔴 只学行为与视觉形态、一行代码不摘。

### 2.2 字号与字体（ZCode `@theme :137`）

- 基准 `--ui-font-size: 14px`；相对刻度：`ui-xl +4 / ui-lg +2 / ui-base / ui-caption -1 / ui-sm -2 / ui-xs -4`（**相对基准的 calc 刻度**——不是一组写死的 px）；
- 等宽字体栈**显式含 CJK**：`ui-monospace, SFMono-Regular, Menlo, Consolas, "Microsoft YaHei UI", "PingFang SC", "Noto Sans CJK SC", monospace`（ZCode 注释：Consolas 无中文字形，默认栈会让中文落宋体——我们代码块/终端同样需要）；
- 中文断行优化：`.text-wrap-phrase`（`text-wrap: pretty` + `line-break: strict` + `word-break: normal`）——标题/描述防"单字断行"。

## 五、技术路线（裁决点）

- **方案 A（建议）**：维持零构建链——CSS 变量 + 组件类 + 内联 SVG 图标 + hash 路由 + 手绘 SVG 图表。代价：recharts 级交互 tooltip 简化（单档 hover 提示）、下拉/对话框手写；收益：约束 3 不破、包体不变、无构建依赖（SEA 教训延续）、改文件即生效。
- **方案 B（需明示推翻约束 3）**：Vite + Tailwind + shadcn 形态组件——交互深度对齐 ZCode；代价：构建链进包、壳资产链重验、THIRD_PARTY 扩容、与"改文件即生效"工作流断裂。
- 图表：方案 A 手绘 SVG（趋势线/甜甜圈/热力图，数据量 ≤ 百点）；方案 B 可直接用 recharts（ZCode 同款）。
