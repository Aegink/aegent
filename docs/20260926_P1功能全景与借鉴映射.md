## 跨组的三个结构模式（P1 批次 1 的结构贡献）

1. **出口级硬拦三连复用**：C46 路径硬拦（T-P1-01）→ C49 ceiling（T-P1-03）→ G7 plan 硬关（T-P1-11）——同一结构（`protected-names` 式清单唯一权威 + gate/revalidate 出口同位 + "规则/白名单不得授权"），`protected-paths.ts` 成为出口级组合的家。链上白名单（meta-ops 放行 todo_write）与出口硬关分层工作：体验归链、安全归出口，后者永远压过前者。
2. **能力面绑定装配**：`todoEmit` / `planMode` 缺省不注册对应工具——"有工具无落流出口/无硬关联动"的残缺面从装配结构上不可交付（不变量 1 与 G7 语义的结构保证）；缺省装配零行为变化（P0 回归用例钉死）。
3. **迁移守卫模式**：`nextSwitchPhase`（换模五态）与 `nextGoalState`（goal 状态机）同款——纯函数合法表 + 表格外抛类型化错误，穷举测试直接钉死；可测性模式在批次内二次复用即成惯例。
