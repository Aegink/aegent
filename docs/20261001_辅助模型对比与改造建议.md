## 0. 结论一句话

参考仓的「辅助模型」= **任务级模型路由（每任务可配模型/档位 + 统一回退链）+ 副调用
任务族（标题/压缩/判官/润色/建议/记忆…）+ 按任务归因的用量观测**。六仓几乎都没有
统一设置 UI（codex 明说缺失、opencode 零 UI、zcode 只有子代理覆盖）——我方做全了
就是差异化。我方内核三任务（判官/摘要/润色）全通，缺口是：**统一副调用底座与
fast-model 回退链（A）、润色设置 UI 整卡缺失（D）、会话标题生成全仓标配而我方没有
（F）、用量按任务归因（G）、每任务真实测试（E）、总闸（H）**。

## 3. 参考仓要点

### 3.1 pi-desktop + cc-switch（润色卡规格最全 + one-shot 基座）

- **one-shot 基座**（`packages/agent-runtime/src/one-shot-complete.ts:77`）：全部无历史
  补全共用——tools 恒空、maxTokens 收口、provider 重试复用、返回 `{text,usage}`、
  错误码参数化（`PROMPT_ENHANCEMENT_EMPTY`/`TITLE_SUMMARIZATION_EMPTY`）。
- **润色回退链**（`agent-ipc.ts:126-172`）：设置 pin → 解析失败 warn+回退会话模型
  （"钉住是偏好不是硬要求"）；reasoning 缺省 off（"改写很少受益于 reasoning"）；
  硬超时 60s（abort+race，错误文案建议换更快模型，不在第二模型上重试）。
- **EnhancementModelCard 全规格**（`EnhancementModelCard.tsx:41-321`）：模型行
  （分组菜单+搜索+第一项固定"跟随当前模型"）+ 不可用标签 + **reasoning 按所选模型
  真实阶梯钳制、换模型自动重钳**；与子代理 pin 选择器共用一套帮手
  （`subagent-models.ts`）——统一"任务→模型"选择件。
- **标题生成**（`session-title-runtime.ts:53-99` + `session-title-summarize.ts`）：
  agent_end 触发、一次性+手动改名守卫、失败静默回退截断提示词、≤25 字符提示词+
  剥引号/前缀/尾标点清洗；usage 在 main 丢弃（反面教材）。
- **cc-switch 无辅助模型面**（prompt 库纯文本）——不必参考。

### 3.2 zcode（标题 sidecar 三件套 + 统一降档函数）

- **统一降档**（`core/model/auxiliary-model-options.ts:9`）：最低公开推理档 + 输出帽
  5000——全部副调用一行接入；请求标 `modelRequestSessionType:"other"`。
- **标题任务**（`title-generation-sidecar.ts` + `session-title.ts`）：唯一独立配置位
  `titleGeneration.{enabled,modelSelection,timeoutMs}`；空配置=跟随会话模型（注释
  明确禁止固化快照）；守卫集（仅 interactive/仅首轮/≥10 字/custom 短路/编辑与 revert
  抑制/automation 关闭）；输出解析兜底链（去 think→JSON→fenced→首行→清洗 ≤100 字）；
  写回竞态 CAS 防护。
- **判官型验证器**（`target-completion-verification.ts`）：会话模型快照、**明确不降档**
  （"Verifier 不能套用低成本降档"）、失败 fail-open、工具调用即 fail-open、busy 专项
  重试、四态事件。
- **观测**：querySource 14 值 → ModelApiOperation/ActorKind 映射；每次模型调用
  `recordModelUsageFact` 落 SQLite（tokens/TTFT/retry/status）；轨迹面板按源打标签。

### 3.3 opencode（small_model 全局字段 + 隐藏 agent 模式）

- **getSmallModel**（`provider.ts:1939-2006`）：`config.small_model` → 插件 hook →
  同 provider 家族优先级自动选型（gemini-flash→gpt-nano→claude-haiku 按 release_date
  挑最新）——不硬编码模型名。
- **每副任务 = 隐藏 agent**（`agent/agent.ts:219-264`）：title/compaction/summary 三
  隐藏槽位，各自 prompt/temperature/全工具 deny；任务模型回退链 = 任务 model →
  small_model → 主模型；**variant 只留给主轮**（small 调用跳过）。
- **压缩四旋钮**（`compaction.{auto,prune,tail_turns,preserve_recent_tokens,reserved}`）
  + env 强制覆盖；压缩产生真实落库消息（token/cost 可分账）；`session.compacted` 事件。
- **UI 零**——配置唯一入口 opencode.json；标题失败静默保留默认（不重试打扰）。

### 3.4 codex（判官路由 + 按任务计费观测）

- **临时结构化请求底座**（`tui/src/temporary_structured_request.rs:51-342`）：ephemeral
  线程+只读+全工具禁用黑名单+30s 超时+8KB 响应上限+取消——全部副调用共用。
- **判官（guardian）**：`approvals_reviewer=user|auto_review` 路由开关 + per-model
  override + 目录协商 Low effort + **目录找不到回退主模型** + prompt 三字段可配
  （`config_toml.rs:198,572-579`）；v2 异步分类器带 `x-openai-subagent: guardian` 头。
- **标题**（`thread_title.rs:29-131`）：小模型硬编码+回退主模型、36 字符/960 字节预算、
  手动改名取消；**recap**：失焦 30min+3 轮启发式+schema 700/200 约束+auto_recap 开关。
- **观测金标准**：ThreadSource 分类（User/Subagent/GuardianReview/Feature/Memory…）+
  ThreadUsage 按 (model,effort,speed) 分组折算 credits/USD + 压缩事件族（前后 token/
  时长/回退计数）。

### 3.5 claude-official（按任务分档语义 + 辅助流量总闸）

- **两类语义**：侧查询（命名/分类）默认走 Haiku（`ANTHROPIC_SMALL_FAST_MODEL`，缺失
  静默回退主模型）；摘要/压缩/回顾走主模型共享 prompt cache（"摘要质量任务不该用
  轻模型"）。
- **总闸**：`CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC` 一键关命名/标题/建议等全部
  副调用；`claude -p` 管道模式直接砍命名请求（按调用面裁剪）。
- **标题工程细节**：短具体名（不复述）、跟随 language 设置、噪声输入（纯链接/插件
  输出）不触发、命名模型拒答不泄漏、手动命名权威不可覆盖、一次生成两消费面（会话
  列表名+终端 tab 名）。
- **hook 三原语**（`mods/types/claude-code.d.ts:2246-2290`）：`model.complete/classify/
  fork`——classify 默认小快模型；fork 共享主缓存前缀并回报 token 用量；模型调用不计
  钩子预算。security-guidance 插件示范 Stop 钩子 LLM 审查+asyncRewake 唤回。
- **去模型化先例**：示例命令建议从 Haiku 调用改确定性生成省成本（CHANGELOG:5307）。

### 3.6 qwen-code（角色模型设置族 + runSideQuery——本轮最佳模板）

- **runSideQuery**（`packages/core/src/utils/sideQuery.ts`）：全部轻量副查询唯一入口
  ——模型链 `override ?? getFastModel() ?? getModel()`；purpose→promptId 归因；
  per-call maxAttempts（装饰性=1）；JSON schema 校验双载；thinking 默认关；语言偏好
  注入；failClosed 开关。
- **角色模型族**（settingsSchema）：fastModel/compactionModel/visionModel/advisorModel/
  imageModel/voiceModel 六角色 + 统一语法 `modelId|authType:modelId` + 运行时 setter
  免重启 + 可用性校验（排除 voiceOnly/imageOnly）。
- **两阶段权限分类器**（`permissions/classifier.ts`）：stage1 极小输出（max_tokens=32）
  ~300ms 快速放行 → stage2 复查（4096）减误杀；fail-closed 且 unavailable 与策略
  block 区分；独立超时 10s/30s。
- **goal-verifier**：副模型对证据窗 accept/reject；证据 256KB 字节预算窗；反注入；
  证据不足=reject。
- **压缩三件套**：专用 compactionModel（未配退主模型，小窗自动回退）；三级阈值阶梯
  （warn/auto/hard）+ 连续 3 败熔断 + 失败分类（空/膨胀/截断）；**cache-sharing 快
  路径**（主模型+原 system/tools 复发吃前缀缓存，失败退冷路径）。
- **成本分级思想**：记忆召回/遗忘选择用 fast，删除决策显式升主模型；insight 分析锁
  主模型+reasoning 开（"quality is the entire point"）；示例装饰性查询 maxAttempts=1。
- **其余任务**：工具批次摘要（~30 字符标签并行隐藏延迟）、next-speaker 检测、vision
  桥（纯文本模型收图→可配 visionModel 或同 provider 自动选→转写替换，failClosed）、
  commit message、推测执行（overlay FS）。
- kimi：requestKind 请求分类学 + 阈值按模型覆写；标题外包云端接口（titleKind 权威级）。
- deepseek：summary 事件落盘记"哪个模型写的摘要"+token+call id（可审计可重放）。
- grok：每任务模型族配置+aux 专属采样配置；hermes：fallback_chain（402 顺链）+
  压缩摘要路由钉扎 + 两段式标题（先确定性后小模型升级）。

## 4. 改造方案（A~K）

### A 统一副调用底座 `runSideQuery`【核心 · 中】

- 新 `src/kernel/side-query.ts`：无历史 one-shot 收敛面——provider/identity 解析
  （任务显式 → enhancement.fastModel → 主模型链）、tools 恒空、maxTokens/超时收口、
  瞬态重试、返回 `{text, usage}`、错误码参数化（`<TASK>_EMPTY`/`<TASK>_TIMEOUT`）、
  `purpose` 归因参数。
- 现有 llm-summarizer 的 requestWithRetry、prompt-polish 的裸 streamChat 循环收敛
  进底座（行为不变，链路单源）。

### B 任务级模型字段补全 + fastModel 全局单点【小】

- `enhancement.fastModel`（{provider,model}）——全部未显式配置任务的缺省轻模型
  （claude SMALL_FAST_MODEL / opencode small_model 语义）；回退链 = 任务显式 →
  fastModel → 主模型（现 resolveEnhancementTarget 扩一档）。
- 每任务补 `fallback`（有序备选，子代理域同构形状）——判官/摘要挂掉时降级路径；
  "跟随主模型"空值语义保持。

### C 润色设置卡补全【中 · 用户可见最大增量】

- enhancement 分节新增润色卡（pi prompt-enhancement-card 全套）：润色模型 pin +
  reasoning + 开关 + 模板编辑器（插入 `{{draft}}` 光标位插入/恢复默认/缺占位符与
  8000 超限实时校验）+ "编辑回默认=清除覆盖" 语义；内核/协议已通（T-P3-146 I），
  纯 UI+save 链。

### D 每任务真实测试按钮【小】

- 每任务行加「测试」：host op 发一次最小真实请求（zcode 1-token 探测语义——
  maxOutputTokens 1、固定 "hi" prompt），回执延迟 + ok/错误；配置错/凭据缺立即
  可见（"确保所有 ui 功能实际可用"的直答）。

### E 会话标题自动生成【中 · 五仓标配新功能】

- 新副调用任务 `enhancement.title`（字段同族；缺省回退 fastModel→主模型）。
- 触发：首轮 turn/end 后异步（不阻塞）；守卫集（仅一次/手动改名短路/首条消息
  ≥10 字/失败静默回退截断 60 字——claude+zcode 守卫集裁剪）；提示词≤25 字符+
  跟随输出语言+清洗链；**总闸关掉不跑**；usage 落账（G）。
- 消费面：会话历史页/侧栏标题显示（现只有时间）；伪会话 id 不落主流（polish 同款
  旁路协议或 host 侧直调——实施按消息链路定）。

### F 用量按任务归因【中】

- request/header reason 枚举扩：`compaction | polish | title | judge | provider-test`
  （副调用统一落 request/header——usage 页已有 request/header 归因链路
  `usageByModel`）。
- usage 统计页加"按任务"分账视图（codex ThreadSource/qwen purpose 语义——判官/
  摘要/润色/标题各自 token 可见）；polish 从"不落账"转正。

### G 辅助流量总闸【小】

- `enhancement.enabled` 总开关：关 = 标题不跑、润色按钮提示已关、判官落回人、
  摘要回退主模型（fail 语义逐任务记档）；设置页顶部开关 + 文案。

### H 判官/压缩语义补强【中 · 择要】

- 判官：对齐 qwen 两阶段语义——stage1 极小输出快判 + stage2 复查（现有 C42 两阶段
  已有骨架，补独立超时与 unavailable≠deny 区分记档）；fail-open/fail-closed 语义
  显式化（策略 ask 复核=fail-closed 落人）。
- 压缩：summary prompt UI 覆写（llm-summarizer systemPrompt 已支持，暴露到设置）；
  阈值/输出帽记档不加旋钮（F11 已定形）。

### I 统一"任务→模型"选择件【中 · 支撑件】

- 分组模型菜单（providers 分组+搜索+"跟随主模型"首项+不可用标签）一次实现，
  判官/摘要/润色/标题四任务卡共用（pi subagent-models 帮手同构；与现有子代理
  模型级联选择器合流）。

### J 明确不做（记档）

- advisor 第二模型工具 / btw 侧问（会话域扩展）/ 推测执行（overlay FS 大工程）/
  vision 桥（纯文本主模型收图场景少，附件已有独立面）/ 记忆抽取代理（无记忆域）/
  下一句建议（Composer 域）/ expert 工作流 / ServiceTier fast-slow（推理档已有
  reasoningEffort 面）/ 云端标题接口（kimi——本地优先原则）。
