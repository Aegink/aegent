## 0. 结论一句话

我方「关于」只有一行硬编码版本号（v0.1.0 写死在 JS 里）——而参考生态把它做成**关于中心**：版本+构建溯源（git SHA/构建时间）并列（qwen/codex 共识）、环境信息分层（轻量进关于卡/深度进 doctor——zcode 字段集最全）、更新检查四件套（启动静默检查+手动按钮+安装方式感知+失败降级——cc-switch/codex/pi-desktop 全有）、会话与数据路径一览（qwen /status paths）、GitHub 反馈预填环境（pi-desktop github-feedback）。建议升级为**「关于中心」四卡组**（版本与构建 / 环境与路径 / 更新检查 / 入口与反馈），与日志中心（T-P3-154）、配置体检（T-P3-153）形成排查闭环。

## 3. 参考仓调研（要点精选）

### 3.4 参考仓共同模式（14 仓归纳）

1. **版本+构建溯源并列是共识**：`v{semver}`+git short SHA（qwen 字段/codex display_version/opencode 构建注入）——裸版本号不足以排查"哪个构建的问题"。
2. **版本单源+构建期注入**：package.json/Cargo.toml 单源，git SHA/构建时间构建期写入生成文件或 env——无一处运行时硬编码在 UI 里。
3. **更新检查四件套**：启动延迟静默检查（1-15s，带配置开关）+手动按钮+**安装方式/发行物形态感知**（便携=只引导下载）+失败降级（静默/软提示，自动检查不弹错）。
4. **提示不强更**：横幅/弹窗+per-version 免打扰（cc-switch dismissedVersion/codex Don't remind/hermes snooze）。
5. **环境信息两层**：轻量层进关于/状态卡（OS/平台/runtime/内存），深度层进 doctor——zcode 的字段集（版本/commit/build time/运行时四件套/OS 五件套/hostname）是"复制诊断信息"的现成格式。
6. **路径一览**：qwen /status paths、pideck AppInfo userDataDir/homeDir——数据落点路径是关于页的排查价值面。
7. **反馈预填环境**：pi-desktop buildBugReportUrl/qwen /bug——issue 链接带版本/平台参数。
8. **changelog 触达梯度**：claude 交互选择器最全/桌面端内置打包或远程拉取+sanitize/最简=跳 release 页——共同点是 markdown 过 sanitize、失败降级外链。

## 4. 关键评估（"和关于这个词的功能不一样"的边界）

1. **更新器归属**：完整下载安装更新器是 **Tauri 壳域职责**（宿主面已有 aegentShowUpdate 接线点，T-P3-114）——本批不做下载安装，做 **UI 侧更新检查卡**：GitHub Releases API 查询（codex updates.rs 同款）+semver 比较+结果展示+**打开 Releases 页引导下载**（=cc-switch 便携版语义，与我方 portable 形态对应）。壳域更新器接入后本卡自动升级为完整链（记档）。
2. **版本单源治理**：构建期注入——copy-assets 阶段生成 `dist/build-info.json`（version+git short SHA+buildTime），host op 读取；UI 不再硬编码（对照 qwen generated/git-commit.ts 模式）。
3. **与体检/日志的关系**：关于中心做**轻量环境+路径**（一眼看）；深度检查归配置体检卡（T-P3-153）、日志归日志中心（T-P3-154）——互相跳转不重复建设。

## 5. 改造方案（A~E 分级，打勾后实施）

分节升级为**「关于中心」四卡组**：版本与构建 / 环境与路径 / 更新检查 / 入口与反馈。

### A 域：版本与构建卡（单源+溯源）

- **A1 构建期注入**：copy-assets 生成 `dist/build-info.json`（version 自 package.json+git short SHA+buildTime ISO）——qwen generate-git-commit-info 模式；portable 打包同步携带。
- **A2 about-info op**：host 读 build-info.json+package.json 缺省回退，返回 `{version, gitCommit, buildTime}`；UI 版本行改读 op（硬编码删除）。
- **A3 便携版徽标**：portable 形态显示徽标（cc-switch isPortable 锚——dist/portable 产物或宿主注入判定，UI 侧由宿主面提示，记档）。

### B 域：环境与路径卡（排查价值面）

- **B1 环境行**：OS（platform+release）/arch/Node 版本/内存 RSS/进程 uptime（qwen systemInfo 字段子集+zcode 格式）。
- **B2 路径一览**：settings.json/logs 目录/事件库/工作区 四行实际路径+每行「打开」按钮（复用 log-open-dir 的 openPathDir 模式泛化为 open-path op）+「复制全部诊断信息」按钮（zcode about snapshot 字段集+pi-desktop 一键复制锚——文本含版本/环境/路径，供 issue 粘贴）。
- **B3 跳转联动**：体检/日志中心跳转链接（已有面引用）。

### C 域：更新检查卡（UI 侧四件套）

- **C1 check-update op**：GitHub Releases API `repos/Aegink/aegent/releases/latest`（codex updates.rs 同款）+semver 比较+8s 超时+失败降级（软提示不弹错）；结果含 latest 版本/发布说明摘要/release 页 URL。
- **C2 UI 行**：当前版本 vs 最新版本+状态（已最新/发现新版/检查失败）+「检查更新」按钮+「上次检查」时间显示（pideck 锚）+「打开 Releases 页」按钮（便携版引导下载语义——cc-switch 锚）。
- **C3 静默首查**：关于中心首次打开时后台查一次（不做启动全量检查——避免每次启动打 GitHub；配置开关记档 P2）。
- **C4**（记档 P2）per-version 免打扰/壳域完整更新器接入（下载安装归壳域）。

### D 域：入口与反馈卡

- **D1 链接行**：GitHub 仓库/Issues/Releases/License（AGPL-3.0）/THIRD_PARTY.md 说明行——openExternal 强制系统浏览器（pideck 锚；受信 URL 白名单）。
- **D2 反馈预填**：「问题反馈」按钮=GitHub issue new 链接**预填环境参数**（版本/OS/arch——pi-desktop buildBugReportUrl 锚）+提示"可附诊断包（日志中心导出）"。

### E 域：保留与记档（P2）

- 壳域完整更新器（下载安装/进度/重启）；per-version 免打扰持久化；changelog 应用内渲染（sanitize 管线）；启动全量静默检查+开关；多语言 changelog 打包（pi-desktop 模式）；源码构建 `v{commit}` 显示（display_version 锚）。

## 6. 待澄清（均有核对支撑）

1. **更新检查目标仓**：`Aegink/aegent`（开源仓）——若发布渠道变化（自有 CDN）改端点即可。
2. **C3 静默首查时机**：关于中心打开时查一次（而非 host 启动）——避免无谓网络请求；若嫌打扰可改纯手动（首版建议：打开时查+手动按钮并存）。
3. **B2 路径暴露范围**：四路径（settings/logs/db/工作区）是否含凭据文件路径——建议不含（凭据路径敏感性高，诊断信息复制时也不含——pi-desktop 不收集凭证纪律）。
4. **A1 构建注入落点**：dist/build-info.json（host 读）vs 编译期 env 注入（opencode 模式）——建议 json 文件（SEA/portable 打包链零改动）。
5. **UI 版本行迁移**：删除硬编码后老用户感知无变化（值相同）——无兼容风险。

### 验收清单草案（打勾后按此实测）

- 版本卡：op 返回 version/commit/buildTime；UI 显示与 package.json 一致；portable 产物含 build-info.json。
- 环境卡：OS/Node/内存/uptime 与真实环境一致；四路径真实存在且「打开」按钮打开对应目录（logs 打开=日志中心同目录）；「复制诊断信息」剪贴板含版本+环境+路径且**不含凭据路径**。
- 更新卡：手动检查→已最新或发现新版（取决于仓上 release）；断网→失败软提示；「上次检查」时间更新；Releases 页链接正确。
- 入口卡：四链接新窗口打开正确；反馈链接 URL 含预填版本/OS 参数。
- 全链：vitest 新单测（build-info 读取/semver 比较/诊断信息文本组装脱敏）+tsc 0+架构 0 error+隔离 host 走查+portable 同步。
