## 一、参考项目的"外观与语言"长什么样

### 1. 主题：行业标配是「跟随系统 + 多预设 + （可选）自定义」

| 项目 | 主题档位 | 跟随系统 | 自定义 |
| --- | --- | --- | --- |
| opencode | TUI 34 内置 + Desktop 36 个 JSON | **system 档**（Desktop: matchMedia 监听 + 双份 CSS 预缓存防闪） | 三层合并（内置<插件<自定义文件），每 token 可写 `{dark,light}` 双值 |
| codex | 38 内置（catppuccin/gruvbox/nord…） | 无 auto 档名，OSC 探测背景明暗自动选预设 | 丢 `.tmTheme` 进目录即被发现 + 启动校验 |
| claude-code | auto/dark/light/×2 色盲友好（daltonized）/×2 ansi = 7 枚举 | **auto 档**一等公民 | `/theme` 内建 GUI 颜色编辑器 + `~/.claude/themes/*.json` |
| zcode | system / zai-dark / zai-light（5 值内部） | system = matchMedia + change 监听 | 无 |
| pi-desktop | system/light/dark/**plugin:\*（主题即插件）** | 双权威（renderer matchMedia + main nativeTheme） | 插件贡献 css+变量 |
| pideck | light/dark/system/**schedule（按时间表自动明暗）**+ 5 皮肤色板卡 + custom | matchMedia + 边界定时器 | custom token 覆盖 + 壁纸图 + 不透明度 |
| cc-switch | light/dark/system | system + **Tauri `window.set_theme` 联动**（system 传 None 保原生标题栏同源） | 无 |
| qwen-code | auto + 15 内置 + 自定义三通道 | auto = OSC 11 探测终端背景 | 内联 JSON / 文件路径 / 对话框 |

**共性结论**：①「跟随系统」几乎是标配（web 系 = `prefers-color-scheme` 一行媒体查询）；②主题不止 dark/light——多预设色板是差异化主体；③实现机制在纯 CSS 世界就是 **data 属性 + token 块**（pideck 三属性：`data-theme`/`data-appearance`/`data-accent`——与零构建链完美契合）。

### 2. 语言：桌面端三态收敛，i18n 均为自研轻量实现（零依赖）

- **zcode（最值得抄）**：`LocalePreference = "system" | "zh-CN" | "en-US"`；**平铺 `Record<string,string>` 词典 + 自研 `formatMessage`（~130 行，`{key}` 占位、缺键回退键名、词典缺失回退缺省语言）**；settings 持久化**双字段**（`localePreference` 用户偏好含 system + `locale` 解析值）；切换即时全树生效；宿主 `app.getLocale()` 优先于 `navigator.language`。
- **pi-desktop**：独立 i18n 包、8 语言、嵌套目录 + TS 类型基准防漏翻；**语言选择器用 endonym（原生名，永不翻译）+ 英文名搜索**。
- **pideck**：两语 + **pseudo 伪语言**（机械生成加长文本专测 UI 溢出）；`TranslationKey = keyof 词典` 编译期强制同构。
- **qwen-code**（CLI）：9 语言 + `language`（auto/自定义包）+ **`outputLanguage`（模型输出语言，独立于界面语言）**——Agent 内核语义上值得注意的分离。
- **hermes**：17 语言 YAML；claude-code：**无 UI 语言**，但有 `language` 设置管**回复语言**。

**共性结论**：界面 i18n 没有一家用重型框架——全部自研轻量词典（50~130 行核心）；「system 跟随 + 手动覆盖」双字段是标准持久化形状。

### 3. 字体/字号/密度——「外观」的另一半语义

- **字号**：zcode `--ui-font-size`（12–20px，**只缩文字 token、刻意不缩间距/图标**）；pi-desktop `--font-scale`（0.8–1.5，乘法缩放整条 text ramp）；pideck 分区字号（UI/会话/输入三独立）。
- **字体**：pi-desktop 系统字体枚举选择器（分组+虚拟滚动+触发器预览）；pideck 基础/等宽字体 + custom 输入 + **CJK 回退链**（防中文落 SimSun）。
- **消息流外观**（聊天产品的"外观"主战场）：zcode 显示推理过程/工具分组折叠；pi-desktop 思考显示 detailed/compact、**会话内容宽度拖拽把手**；grok/hermes 时间戳开关；codex 动画总开关 + 6 特效细粒度；hermes 皮肤（品牌级视觉包）。

## 二、我方现状

**底子（好）**：theme.css 全站唯一取色处（132 行 token——色板/字号 calc 刻度/轨迹六色/代码高亮四档），`body[data-theme]` 双主题切换机制全端一致、即改即存且启动即应用。token 化的字号体系意味着**字号档位 = 改一个基准 token**。

**断点（"和外观这个词不一样"的根源）**：
1. **语言下拉是摆设**——`appearance.language` 落盘 + 枚举校验，但**全 UI 零消费点**（无 i18n 词典、无 t()、无 document.lang）：选 English 界面纹丝不动。这是 bug 级的诚实性缺口。
2. **主题只有 dark/light 两档**——无「跟随系统」档（WebView 下 `prefers-color-scheme` 是免费的）、无预设色板、无强调色个性化。
3. **无任何个性化**——字号/字体/密度/消息流外观（推理显示、时间戳、内容宽度、动画）全部缺失；UI 字号在低分屏/高分屏不可调。

## 四、实施记录（2026-09-30 用户裁决"全做 + 主题插件化"——主题插件从 F 项不建议名单捞回）

- **A 主题系统升级**：`applyAppearance` 全量外观引擎（state.js——applyTheme 保持旧签名兼容）：主题模式四档（**system** = matchMedia+监听 / dark / light / **schedule** 按时间表——pideck 边界定时器同款，跨午夜区间合法）+ `data-appearance` 皮肤五预设（默认/Catppuccin〔暗 mocha·亮 latte 双变体〕/Tokyonight/Nord/Solarized〔双变体〕——theme.css token 块，色值唯一处纪律延续）+ `data-accent` 强调色六预设（Sky/Green/Violet/Amber/Rose/Cyan——brand/chart-1 联动）。
- **主题插件化**（用户点名，pi-desktop 主题即插件同构）：plugin.json 清单闭集追加 `theme` 字段（{name?, base: light|dark, css: 相对文件}——绝对路径/上跳拒绝）；**入口按需**（声明 capabilities/hooks 才要求 index.js——纯主题插件零代码合法，内核装载面照旧 never-fail）；host `plugin-theme-css` op（路径收敛插件目录内 + 256KB 上限 + 类型化拒绝）→ UI 注入 `<style id="aegent-plugin-theme">` + `data-plugin-theme` 属性——**插件主题压过皮肤/强调色**（pi-desktop 回退语义：停用即回基础主题）。
- **B 真 i18n（b1 起步）**：`ui/i18n.js` 自研 t()（zcode 模式——**中文原文即键**的平铺词典，未翻译回退中文原文、批次渐进零破坏）+ `ui/locales/en-US.js`（批次一覆盖 = 骨架导航 + 设置域框架 + 外观页全部）；`data-i18n/-title/-placeholder` 三挂点静态扫描；语言三值（system 跟随 navigator / zh-CN / en）——切换保存后整页刷新生效；`document.lang` 同步。批次二 = 对话域与深处分节文案（词典补条目即可，调用点零改动）。
- **C 字号与字体**：UI 字号四档（12/14/16/18——`--ui-font-size` 基准 token 覆写，calc 刻度全站联动，只缩文字不缩间距——zcode 安全缩放）+ 界面字体（默认/无衬线/衬线/自定义）+ 等宽字体自定义——**自定义族自动追加 CJK 回退链**（防中文落宋体）。
- **D 消息流外观**：显示推理过程开关（`body.hide-reasoning .line.reasoning` CSS 面）+ 显示时间戳（气泡尾 `.msg-time`——渲染期判定，恢复视图与 live 流一致）+ 会话宽度三档（标准 820/宽 1100/全宽）+ 动效总开关（`body.no-anim` + `prefers-reduced-motion` 系统偏好双保险）。
