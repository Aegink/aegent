- **卡式结构**：编号（建议 S0-xxx 脚手架 / S1-xxx 底座 / S2-xxx 协议与适配 /
  S3-xxx 视图分期 / S4-xxx 工程与合规），每卡：动作 / 验收 / 依赖 / 依据；
