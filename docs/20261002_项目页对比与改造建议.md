## 0. 结论一句话

参考仓共同把"项目"做成**三层结构**：①项目 = 目录绑定（逻辑项目组可含多文件夹+primary
根）②任务 = 项目内的会话（归属 projectId、标题自动生成、删除/重命名带所有权保护）
③文件 = 项目根白名单内的只读浏览（懒加载树 + 预览 + 右键菜单）。用户点名的三件套参考
仓全部有现成蓝本：**pi-desktop 的添加三模式**（文件夹多选/Git clone/会话扫描导入自动建
项目，三者收敛同一条建组语义）、**zcode 的文件右键菜单 7 项**（打开/打开方式/资源管理器
/复制相对·绝对路径/添加到聊天——与本需求逐字对齐）、**pideck 的任务目录层**（SessionCatalog
+ 标题三重防线 + 运行中阻止删除）。我方现状只有一个 `{name, workspace, instructions}`
三元组 + "新建/设为活动"两个按钮——任务、文件树、导入、多文件夹全缺。改造主体：项目页
独立成页 + 项目模型升级（id/多文件夹/时间戳）+ 任务（=会话归属项目）+ 文件树/预览/右键
菜单（host 白名单 + realpath 边界）+ 扫描导入（先"发现建项目"，会话内容导入二期）。

## 2. 我方现状与差距

现状基线（本会话逐文件核对）：

- **数据面**：`src/session/settings.ts:127` ProjectEntry = `{name, workspace,
  instructions?}` + `activeProject`；无 id、单文件夹、无时间戳、无任务归属。
- **UI 面**：`ui/views/settings/system.js:41` "数据与系统"组里的项目分节——新建项目 +
  列表 + 设为活动（语义 = 新会话以该项目 workspace 启动）；无任务、无文件树、无导入。
- **消费点**：activeProject → 新会话 `--workspace`；项目指令 → 指令中心 project-agents 层。
- **可复用基建**：T-P3-148 插件市场的 `plugins-marketplace-git.ts`（runGit 净化 env +
  sha pin + 30s 超时——Git 仓库添加模式可直接复用）；`ui/render.js` renderMarkdown
  （Markdown 真渲染直接复用）；@ 文件补全（mention 注入的对端）；T-P3-147 title 辅助
  任务路由（标题 LLM 总结直接复用）。

**与参考仓的差距**（每条有 §3 先例）：无任务概念、无文件树/预览、无右键菜单、无 Git 仓库
添加、无扫描导入、单文件夹无项目组、无标题自动生成、无排序/搜索/最近打开、无删除保护。

## 4. 共同模式提炼

1. **项目=目录绑定，canonical path 即身份**：dsh realpath 即 canon、pi-desktop 项目组
   folders+primary、hermes project_folders——同路径幂等复用是标配（我方现状重名直接
   建重复条目）。
2. **三模式一条语义**：pi-desktop 文件夹/Git/导入三源全部收敛 `createNamedProjectGroup`
   ——我方三模式也应共用"建项目记录+激活"一条链。
3. **任务=会话+归属**：三家全部是"会话带 projectId/projectPath"，不是独立任务实体——
   我方的任务天然映射为"会话 + 项目归属字段 + 标题"。
4. **标题自动生成都有所有权防线**：首条消息截断即时回退（零成本）→ LLM 总结（跳过手动
   命名）→ titleLocked/claimTitleOwnership（手动名永不被覆盖）——pideck 三重防线最完整。
5. **删除都是保护性的**：两段式确认 + 运行中阻止 + 磁盘消失仍可删（pi-desktop）+
   回收站（pideck 文件删除）。
6. **文件面统一"只读+懒加载+配额+白名单"**：单层列举+hasChildren、条目/字节双 cap、
   realpath 边界（pideck isPathInsideProject / dsh outside-workspace）；zcode 服务层
   无边界是**反例**（其媒体预览漏洞修复注释自证）。
7. **预览/源码切换是"模式"不是"双栏"**：zcode 的按文件类型定默认值 + 菜单切换 + code
   模式联动自动换行，是我方 md 预览的直接蓝本。
8. **右键菜单 zcode 7 项即规格**：用户需求清单与之逐字对齐；"添加到聊天"= mention 注入
   （`[name](./rel/path)` 格式，非附件）。
9. **导入的核心工程细节**：确定性幂等 ID（`import-<source>-<externalId>`）+ 三计数回执
   （imported/skipped/failed）+ 大档案采样（250 文件/5MB 阈值）+ 候选 key 校验防伪造。
10. **missing 标记不误删**：目录暂时不可达（网络盘/移动盘）只标 missing，删除靠用户。
