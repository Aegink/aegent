### 技术教训清单（防复发——全部是真实踩过的坑）

- **持久化**：--host-db（host 面）与 --db（child 面）是两个参数，缺一事件不落盘；事件权威=child（turn 末 flush+启动 restore），host 镜像=纯内存读面；双进程写同库靠 busy_timeout=5000。
- **restore 三级降级**：strict→lenient（seq 断续容忍）→discard（投影 skipTo(maxSeq) 锚）；fail-closed 前先想"fail 的代价谁承担"——启动失败=整个会话死。
- **工具注册**：BUILTIN_TOOL_NAMES 顺序必须与注册执行顺序一致（测试 toEqual 深比较含序）；descriptions 文件名=工具名（下划线），新增工具三处同步（代码+描述+名单）；工具必须带完整 parameters schema（空 schema=模型无从传参全失败）。
- **UI**：新设置分节必须用既有行卡体系类名（group-title/row-list/row/row-copy/row-control/tabs-pill/switch）——发明不存在的类名=静默塌陷；.card 是聊天流审批卡样式不可挪用。
- **JS 工程**：动态 import 相对路径按源文件位置解析（views/settings/ 下是 ../../）；async 事件 handler 必须 catch（静默吞=死按钮）；python 批量改 JS 源码时 `\n`/`\s` 转义会丢——用 Edit 工具或四重转义核对。
- **构建**：vitest 全量期间禁并行 build；dist/portable 残留进程锁 build（node.exe 被占时 mv 改名绕锁再拷）；exe 锁定用改名绕锁法。
- **实测**：走查用 echo provider 不暴露 schema/模型类缺陷——**必须真实模型轮验证**；IAB evaluate 是隔离 world（改全局变量不落地）；CDP 壳内实测走 remote-debugging-port=9223；日志定位看 ~/.aegent/logs/agent-YYYYMMDD.log 的 spawn/exited 对。
