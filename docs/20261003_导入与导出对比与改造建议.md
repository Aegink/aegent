## 0. 结论一句话

我方「导入与导出」只有一个整包下载+整包导入+深链接收端（约 90 行 UI），而参考生态把同一词做成了**数据生命周期管理**：配置包选择性导出与版本迁移（qwen 迁移链）、备份中心（cc-switch 三层备份可恢复）、会话导出为 md/html/json 且带脱敏（qwen/pi/kimi/hermes）、分享链接双向（cc-switch deeplink 风险分级）、配置体检（claude/codex doctor）。建议把该分节升级为**「数据中心」五卡组**（配置包 / 备份 / 会话导出 / 分享 / 体检），A~F 六域落地。

## 2. 我方现状（本地源码深读）

### 2.1 transfer 分节现状（ui/views/settings/system.js:52-76 + src/session/settings-transfer.ts）

- **导入**：文件选择 → `summarizeImported` 摘要 12 项 + 4000 字符预览 → 确认模态 → `op:"import"` → host `applyImportedSettings`（settings-transfer.ts:120：**整份替换**，仅 onboardingDone 不覆盖/activeProfile 同名保留）→ `backupSettingsFile` 滚动 5 份（bak.0~4，settings-transfer.ts:147）→ UI 全量回填。

- **备份不可见**：bak.0~4 只写不读，无列表/恢复/删除面。

### 2.2 域外既有导入/导出面（盘点——避免重复建设）

## 4. 参考仓共同模式（14 仓归纳）

1. **凭据与配置物理分离是默认前提**：codex auth.json / pi auth.json 0600 / pi-desktop credentials 哈希化；我方零凭据包+DPAPI credentials.bin 已达标，**反而比 cc-switch（整库 SQL 含 key 无提示）更严**——保持。
2. **导出=人类格式（md/html）+机器格式（json/jsonl）双轨**：md 优先（三家 /export），json 可回导（opencode/pi/kimi）；jsonl 为会话存储通用形。
3. **脱敏层凡"数据离开本机"必有**：opencode --sanitize 递归 redact / hermes /save redact / pideck 备份查看打码 / cc-switch deeplink 预览脱敏。我方导出无脱敏选项（配置包不需要，会话导出需要）。
4. **危险防线阶梯**：确认弹窗 → 恢复前自动留退路（pideck pre-restore、cc-switch safety backup）→ id/路径白名单校验（pideck 备份 id 正则、qwen realpath 三阶段）→ DryRun 默认（codex migrate-rollouts）→ 导入的服务默认不启用（pi-desktop MCP disabled 剥离）。
5. **幂等是导入硬约束**：opencode upsert / pi-desktop 确定性 ID / T-P3-150 registry 账——我方已有，沿用。
6. **备份三层**：手动+周期+破坏性操作前 safety；可恢复/删除/（重命名）；清理保护源与安全备份。
7. **版本化迁移链**：qwen $version+正/降双向收敛调度器是标杆；pi session v3 逐级迁移；codex 无版本但 DryRun 迁移。
8. **doctor=只读诊断+脱敏输出+可跳转修复**：codex 只读契约 vs claude 可修复；检查项均含"失效引用类"（marketplace 失效条目/托管 settings 坏行）。

## 5. 改造方案（A~F 分级，打勾后实施）

分节升级为**「数据中心」**，五卡组：配置包 / 备份 / 会话导出 / 分享 / 体检。transfer 现有两行功能全部保留语义不丢。

### A 域：配置包 2.0（选择性导出+版本迁移+域合并导入）

- **A1 选择性导出**：导出改模态——域勾选清单（供应商/提示词/MCP/项目/外观/快捷键/增强/界面行为，与 summarizePackage 域对齐）+条目计数预览+零凭据明示+文件下载。UI 侧按域过滤 settingsCache 生成部分包。锚：pi-desktop 十域白名单（domains.rs:24-66）、cc-switch 导出仅 toast 路径（反例→我方导出前摘要确认）。
- **A2 部分包域合并导入**：包形状 v2 增 `partial:true + domains[]`；host `op:"import"` 扩 `mode:"replace"|"merge"`——replace=现整份替换（v1 兼容），merge=仅覆盖包内所含域、本地其它域不动（按域校验，复用 parseSettingsShape 域解析子函数）。锚：opencode import upsert 幂等（import.ts:186-225）。
- **A3 包版本迁移链**：`version` 起真链——buildImportPreview 校验版本，低于当前跑 `PACKAGE_MIGRATIONS`（v1→v2 空操作示范位+结构），高于当前拒绝并提示升级。锚：qwen `$version`+MigrationScheduler+DOWNGRADE 双向收敛（settings.ts:116、migration/index.ts:31-79）。

### B 域：备份中心（cc-switch BackupListSection 对齐）

- **B1 备份列表卡**：枚举 settings.json.bak.0~N（时间/大小/序号）+「立即备份」按钮。host 新 ops：`settings-backup-list` / `settings-backup-create`。
- **B2 一键恢复**：列表行「恢复」→ 确认模态（文案明示"恢复前自动备份当前配置"）→ host `settings-backup-restore`：**恢复前先做 safety 滚动备份**→ 写回→ 返回新设置→ UI 全量回填（同导入路径）。锚：cc-switch restore 前置 safety+toast 回显（BackupListSection.tsx:90-103, backup.rs:1002-1088）、pideck pre-restore（ConfigBackupManager.ts:14-15）。
- **B3 备份删除**：单删+确认模态；host `settings-backup-delete`（文件名白名单只许 `settings.json.bak.\d+` 形状——pideck backupIpc id 正则锚 backupIpc.ts:21-55）。
- **B4**（记档 P2）周期自动备份（interval+retain 两参，cc-switch periodic_backup_if_needed backup.rs:413-473）。

### C 域：会话导出（数据出库——本批最大新增能力）

- **C1 会话导出三格式**：`md`（人类阅读）/`html`（自包含+主题）/`json`（机器可回导 `aegent-session-export v1` 包）。落点：聊天页头部动作+历史页会话行「导出」。host op `session-export(sessionId, format, redact)` 从事件库取数序列化（复用 T-P3-150 事件→消息链正向）。锚：qwen 四格式 SSOT（exportCommand.ts:492）、pi 自包含 HTML（core/export-html/）、codex Copy/Save 二选一（transcript_export.rs:27-71）。
- **C2 脱敏选项**：默认**开**（密钥模式正则 redact：sk- 前缀/凭据引用等），可关。锚：hermes /save redact（cli_session_mixin.py:620）、opencode --sanitize（export.ts:11-220）、pideck SECRET_KEY_NAMES 打码（ConfigBackupManager.ts:55-56）。
- **C3 会话 JSON 回导**：导入 `aegent-session-export` 包为新会话（转 events→appendBatch→registry 幂等账，与 T-P3-150 同构；UI 入口放历史页）。锚：pi /import 确认流（interactive-mode.ts:6308）、opencode import 幂等。

### D 域：分享升级（深链双向）

- **D1 生成分享链接**：导出模态「复制分享链接」→ `aegent://import?data=<encodeURIComponent(配置包)>`（接收端 window.aegentApplyDeepLink 已在）+体积阈值提示（>50KB 建议用文件——URL 过长渠道不适配）。
- **D2 导入预览风险标注**：预览摘要对供应商 endpoint（localhost/内网段→"内网端点"黄标）与可疑 env 键黄标。锚：cc-switch deeplinkRisk 三级（deeplinkRisk.ts:8）+预览递归脱敏（deepLinkConfigPreview.ts:12-35）。

### E 域：配置体检（doctor 化——扩出"导入与导出"字面）

- **E1 配置体检卡**：host op `settings-checkup` 只读检查行式返回 `{level: ok|warn|fail, item, detail, section?}`：defaultProvider 引用存在/providers 必填字段完整/MCP 命令与 URL 可解析/prompts roots 目录存在/备份链健康（bak 文件可读）/各 provider 凭据有无（只报有无不读值）/键位冲突。fail/warn 行可点击跳对应设置分节。锚：codex doctor 只读+脱敏+可序列化契约（doctor.rs:1-10）、claude /doctor 失效条目检查（CHANGELOG:3321）+可修复（:2478）。实现位：settings-sandbox-doctor.ts 同层新域文件。

### 验收清单草案（打勾后按此实测）

- 配置包：八域勾选导出→检查包内只含勾选域+零凭据断言；部分包导入另一隔离实例→仅勾选域变更其余不动；v1 旧包导入行为不变；伪造高版本包被拒。
- 备份：立即备份→列表出现；恢复→确认文案含 safety 提示→恢复后 UI 回填正确→列表多出恢复前 safety 备份；删除→确认→消失；非法文件名操作被拒。
- 会话导出：md/html/json 三格式各下一份（脱敏开）→md 可读/html 打开有主题/json 重新导入→新会话消息一致→registry 幂等（重导 skipped）；脱敏关→密钥原样（在凭据面录入的测试 key）。
- 分享：生成链接→粘贴到新实例深链→三确认→导入成功；>50KB 包提示用文件。
- 体检：制造坏数据（删 prompts root 目录/凭据清空）→体检 fail 行出现→点击跳对应分节。
- 全链：vitest 新单测（迁移链/域合并/备份 ops/脱敏正则）+tsc 0+架构 0 error+隔离 host 四旗标+USERPROFILE 隔离走查+portable 打包同步。
