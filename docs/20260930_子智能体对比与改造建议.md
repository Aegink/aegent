## 3. 参考仓要点

### 3.1 pi-desktop（★ 主参考，截图即它）

- **管理页**（`AgentSubagentsPage.tsx`，472 行）：内置组 + 全局组（组头带
  `~/.agents/subagents` 路径）；行 = 图标 + 名称 + `Task({name})` handle 副标题 +
  描述 + 工具 `<code>` 徽标 + 内置/仅全局 badge；内置行操作 = **「复制为我的定义」**
  （`copyBuiltin` → `draftFromDefinition` 预填编辑器，同名后按钮隐藏）+ 启停
  （乐观更新）；自定义行 = 编辑/Reveal/两段式删除/启停；搜索匹配名称/handle/描述。
  管理页**无诊断面板**（解析诊断只进会话启动日志）。
- **新建/编辑模态**（`SubagentEditorSheet.tsx`，823 行）——对照截图逐项：
  - **模板 chips**：`PresetPicker` 仅创建时渲染；`applyPreset` 整体覆盖
    name/description/tools/body，清 inherit 标记，**保留用户已选 model/scope**；
    空白 chip = 重置。五预设字段全文在 `shared/subagent-presets.ts:39-195`，与
    运行时 inline 文档双源同步（测试锁定）。
  - **名称→骨架 seed**：新建时输入名称且 body 空 → 一次性写入
    `subagentTemplate(name)`：`## What to do / ## What to report back（"the parent
    agent only sees your final message, not your steps"）/ ## Limits`。
  - **何时委派给它** = description 字段（zh 文案；提示语"这是主智能体委派前唯一
    能看到的内容"）；**不进系统提示**——拼进 Task 工具描述的子代理目录
    （`runtime.ts:4113-4119`：`- name (tools: …): description Default model: …`）。
  - **可用工具**：`SUBAGENT_ASSIGNABLE_TOOLS` 7 个固定 chip；Bash/Edit/Write 标
    `is-mutating` 高亮 + "可自行改动文件"提示；数据形状 = 一个 tools 数组，
    **继承时把 token `"inherit"` 放首位**（如 `["inherit","Bash"]` = 父全集 ∪
    显式 extras − 拒绝清单〔Task 系/模式切换等〕）；不勾继承且不选 = 默认只读
    三件（`DEFAULT_SUBAGENT_TOOLS`）。
  - **指令 32KB**：`MAX_SUBAGENT_BYTES = 32*1024`（前后端同值）；TextEncoder 计
    字节，>80% 黄（is-near）、>100% 红（is-over）。
  - **高级区**：模型下拉只列**可运行**（有密钥/OAuth）的 provider 模型，pin 写成
    `provider/model`，空值=「与会话一致」；orphan pin 失配保留显示；无可用模型给
    "前往模型设置"按钮。**推理强度** = `""(与会话一致)/omit(不传递)/off/minimal/
    low/medium/high/xhigh/max` 8 档白名单。**备用模型** = 有序列表（↑↓ 排序 +
    下拉添加，排除主模型与已选）。**输出上限** = maxTokens 数字输入，placeholder
    「跟随模型」，1..200_000，语义 = **单次响应** output cap。
  - **作用范围**：**没有选择器**——只有「全局级·所有项目生效」标签 + HelpIcon
    说明"子智能体仅支持全局级"（决策 D202；`scope` 字段协议兼容保留但 no-op）。
  - **校验**（`subagentDraftError`）：slug 非空、描述必填、工具至少一个或继承、
    model 必须 provider/model 形状、maxTokens 范围、body 非空 ≤32KB。
- **消费面**：Task 工具（参数名 `agent`）+ **后台委托生命周期**——立即返回
  delegationId，`TaskWait`(any/all+minCompleted)/`TaskList`/`TaskStop` 三工具 +
  心跳行；并发上限 10；模型优先级 `Task.model > definition pin > 会话模型`，
  fallback 运行中换模（仅 provider 终态错误触发）；推理强度 `omit` 直传否则
  clamp；maxTokens 进 model binding 覆盖；**父上下文防火墙**——子消息行带
  `parentToolCallId`，重建父上下文时一行 `continue` 跳过；子报告 12K 截断 +
  TaskWait 汇总 50K 上限；resume 链（ADR 0279）。
- **host-core**（`user_subagents.rs`，812 行）：实体 = markdown 文档
  `~/.agents/subagents/<id>.md`（frontmatter 全字段）+ 启停状态另存 JSON
  （内置开关独立文件防 prune）；校验：slug ≤40、描述 ≤400、**最多 64 个**、
  文档 ≤32KB、工具白名单（未知静默丢弃+大小写归一）、thinking 8 档、model
  `provider/model`、maxTokens 钳制。

### 3.2 zcode

- **三来源 + 插件**：`~/.zcode/agents/**`（用户）、`<ws>/.zcode/agents/**`（项目）、
  插件 `agents/*.md`（命名空间 `plugin:bare` + 歧义诊断 + 版本无关稳定 id）；
  **md 文件 + agents-state.json 双层存储**——启停/模型覆盖不进 md（只读的内置/
  插件也能有用户级模型覆盖，插件升级不丢）。
- **frontmatter 全集**（`profile.ts:21-38`）：name/description/systemPrompt/color
  (8 色)/modelSelection(model+reasoning)/tools/disallowedTools/skills/
  permissionMode(auto|plan)/maxTurns/memory/background/injectAgentsMd/mcpServers。
  **宽松 frontmatter 解析**（坏字段拒字段不丢文件）；**项目级 profile 强制剥离
  permissionMode**（防仓库文件提权子代理）。
- **管理 UI**（`SubagentsSection.tsx`，1841 行）：三分组（user/plugin/built-in）+
  行内 model+reasoning 覆盖（内置/插件只读 profile 的唯一配置入口）+ scope 菜单；
  **无导入扫描 agents 类目**（settings-sync 五类目不含 agents；也无 .claude/agents
  批量导入）。
- **消费面独特点**：**无 fallbacks**（单 modelSelection）；**后台三通道**（参数/
  frontmatter background/**autoBackgroundMs 前台超时自动转后台**）+ 后台产物
  文件三元组；**SendMessage 续聊/steer/停止代理可被消息 resume**；**per-agent
  持久记忆**（memory: user|project|local → 独立 MEMORY.md 目录 + 自动补
  Write/Edit）；**MCP 借用**（child 不自建连接，borrow 父快照 + mcpServers
  白名单 + 启动期硬校验）；所有子代理强制剔除 plan mode 工具（防卡死）；@-mention
  子代理入口 + 子代理目录 side pane（点开子 transcript）。

### 3.3 opencode

- **agent 定义**：内置硬编码（build/plan/general/explore/compaction/title/summary）
  + 配置 `agent` 键 + `{agent,agents}/**/*.md` 三层逐字段 `??` 覆盖；`disable:true`
  直接删除 agent；字段全集含 **mode 三态**（primary=主对话/subagent=仅 task/**all=
  双向**）、hidden（@ 菜单隐藏但模型可调——programmatic-only）、temperature/top_p、
  **permission 规则集**（allow/ask/deny + glob，细到 bash 单命令/edit 路径/
  **task 子代理名**）、steps（软熔断：到上限注入"工具已禁用，输出总结"而非硬断）。
- **管理**：**无图形管理面**；CLI `opencode agent create` 用 **LLM 生成**
  identifier/whenToUse/systemPrompt（注入已占用名单防撞名）；`agent list`；
  TUI Tab 切换 + @ 菜单。
- **消费面**：task permission 按"谁能调哪个 subagent"做 glob 控制，**deny 的
  subagent 从工具描述中彻底抹除**（模型看不见）；子会话权限只继承父的 deny +
  external_directory（allow 不下传——防越权放大）；task_id 会话续跑；后台子代理
  完成后结果自动注入父会话（提示语禁止轮询/重叠劳动）；深度限制 subagent_depth。

- **kimi-code**：**AgentSwarm**——单次调用按 `prompt_template`（`{{item}}` 占位）×

- **qwen-code**：**executor 外包**——subagent 可声明 `executor: {kind:'acp'|

## 4. 改造方案（A~F）

> 顺序即依赖序；E 含内核小扩（schema/消费面），其余 UI 为主。零新增依赖。

### A. 编辑器重做（对照截图全链）

- **模板 chips**（仅新建时渲染）：五预设 + 空白开始；点击 = 整体覆盖
  name/description/tools/prompt（保留已选模型/推理等高级字段——pi-desktop
  applyPreset 语义）；预设值直接复用内核 `BUILTIN_SUBAGENTS`（单一事实源，
  无需第二份 preset 表——我方内置就在代码里，UI 直接 import）。
- **名称→骨架 seed**：新建输入名称且 prompt 空 → 一次性填中文骨架
  `## 任务 / ## 汇报要求（父会话只看你的最终消息，看不到你的过程）/ ## 限制`；
  手写过不覆盖（技能页种子同款门控）。
- **指令字节计数**：`n / 32KB`，>80% 黄、超限红 + 保存禁用；**内核配套**：
  `SubagentDefinition.prompt` 加 32KB parse 校验（settings parse 层——prompt 进
  子装配系统提示，超大会炸上下文，fail-closed）。
- **description 引导**：label 改「何时委派给它」+ hint「这是主代理委派前唯一
  能看到的内容」。
- 落点：agents.js 子代理编辑器段 + settings.ts parse。

### B. 工具集形态升级

- 「继承主会话工具」checkbox（勾 = tools undefined 不限——数据面不动，UI 显式化）
  + 工具 chips 多选（候选 = ready 注册表面，既有 chip-picker 数据源）；不勾继承
  时至少选一个（校验提示——pi-desktop 同规则）。
- **mutating 高亮**：bash/edit/write chips 标警示色 + title"可改动文件/执行命令"。
- 落点：agents.js（数据形状不变——`tools?: string[]`）。

### C. 高级折叠区（默认收起，编辑时展开）

- **模型**：provider/model 两文本框升级为**下拉级联**（条目下拉 + 模型 id 下拉，
  复用场景档页 `PROFILE_ADAPTER_WIRE`/供应商页级联形态；空值 = 「与会话一致」
  ——既有回退链语义不变）。
- **推理强度**（新增）：下拉 `与会话一致 / 不传递(omit) / minimal / low / medium /
  high`；`SubagentDefinition` += `reasoning?: string`（"omit" 哨兵 + THINKING_LEVELS
  白名单）；**消费面**：`resolveSubagentModel` 产物 RegisteredModel 的 options 带
  reasoning（T-P3-137 四轮的 reasoningEffort 请求面已通——子代理独立模型链
  直接复用；"与会话一致"= 不设字段走父值）。
- **备用模型**：fallbacks 逗号文本框升级为**有序下拉列表**（添加按钮 + ↑↓ 排序
  + 移除；候选同模型级联数据源；排除主模型与已选）。
- **输出上限**（新增）：maxTokens 数字输入，placeholder「跟随模型」，范围
  1..200_000；`SubagentDefinition` += `maxTokens?: number`；消费面 = 解析产物
  options 的输出上限覆盖（实施时核对适配层 request 面——模型条目 maxOutput
  已有同形状字段）。
- 落点：settings.ts（schema+parse）+ subagents-config.ts（类型）+ subagent.ts
  /agent-process.ts（消费透传）+ agents.js（UI）。

### D. 内置行「复制为我的定义」

- 内置行加按钮（无同名用户条目时显示）：预填编辑器（name/desc/prompt/tools
  全量拷贝）——比"同名覆盖"更显性的定制入口（pi-desktop copyBuiltin 同构）；
  已有同名用户条目时隐藏（覆盖记录折叠展示不变）。

### E. 列表行增强

  我方 task 工具 subagent_type 取值即 name）。

## 4G. 异步委托与子会话查看（用户追加指令后的扩展评估）

> 用户裁决：**要做异步**，且要求①子代理可在侧边栏打开看实际会话过程（zcode
> SubagentDirectorySidePane 形态）②最终结果正确返回父会话。本节是全面评估。

### G0. 我方内核的三个关键既有事实（评估基线）

1. **子会话事件已全程落库**：子 loop 以 `childSessionId + store` 构造
   （`subagent.ts:257-262`）——每个事件落独立流。**"侧边栏打开看过程"的数据面
   天然成立**，且我方子消息落在**独立流**而非父流——zcode 需要"父上下文防火墙"
   （重播跳过带 parentToolCallId 的行，`runtime.ts:2716`）解决的问题在我方**结构上
   不存在**（父流里根本没有子消息）。
2. **打开历史会话的通道现成**：`viewSession(s)`（`ui/views/history.js:74-87`）=
   `sendQuery({sessionId, op:"events"})` 拉快照 → `renderHistory` 只读回放。task
   工具结果的 `meta.subagent.sessionId` 已经落流（`task.ts:150`）——**task 卡片点击
   打开子会话的入口数据齐了**。
3. **收敛钩子与队列在位**：父 turn 的 `decideTurn` 是装配钩子（`wrapDecideTurn`，
   `subagent.ts:264`）；step 边界 `drainQueue` 注入 user/message 进模型历史
   （`loop.ts:725-744`）——**委托完成报告可以走队列注入**，这是"结果正确回流"的
   最小侵入路径（pi-desktop resumeAfterDelegations 的我方等价物）。

### G1. 异步委托生命周期（内核）

- **委托注册表**：`createSubagentRunner` 闭包内 `Map<delegationId, {childSessionId,
  agentName, description, status: running|completed|failed|cancelled|stopped,
  startedAt, 报告, cancel()}>`（delegationId = `dlg-<n>` 递增）。并发上限
  `MAX_SUBAGENT_DELEGATIONS = 10`（pi-desktop 同值）——满时 task 后台启动类型化拒绝。
- **task 工具** += `run_in_background` 参数（zcode/kimi/qwen 同名参数）：true 时
  启动子 loop **不 await**（既有子装配/工具收窄/沙箱切片/独立模型全复用）→ 立即
  返回 `已启动 delegationId=dlg-N（子会话 <id>）——用 task_wait 收割结果；期间可
  继续其他工作`。启动失败照旧类型化回喂。
- **三个新工具**（registry 注册，pi-desktop SUBAGENT_* 生命周期收敛为我方版）：
  - `task_wait`：参数 `{ids?, mode?: "any"|"all", min_completed?, timeout_ms?}`——
    await 注册表收敛 → 每委托一段 `<task_report id state>`（成功=最终消息、
    失败/取消=错误；**报告截断 12K**——pi-desktop MAX_SUBAGENT_REPORT_CHARS 同值，
    头尾保留）。
  - `task_list`：全部委托状态清单（id/agent/描述/状态/耗时/子会话 id）。
  - `task_stop`：停止指定委托（cancel 子 loop → 结算 stopped）。
- **结算收敛（结果正确回流的保证）**：装配侧 `wrapDecideTurn` 扩展——end 裁决前
  查注册表有 running 委托 → **等待全部结算** → 每委托报告 enqueue 进父 loop 队列
  （截断同上）→ 返回 continue → 下个 step 边界 drainQueue 把报告落成 user/message
  → 模型看到结果继续（总结/再派活）。**即使模型忘了 task_wait，turn 想结束也会被
  拦住注入结果**——"正确返回"不依赖模型自觉。
- **生命周期边界**：委托随父进程活；父会话收尾（mcpConnections dispose 同款纪律）
  时 stop 全部在途并结算 stopped；**父 turn 取消不取消后台委托**（后台语义——
  zcode 同构；父会话级收尾才是终止点，记档）。前台 task（run_in_background 缺省
  false）行为完全不变（同步 await，既有语义零风险）。

### G2. 子会话侧栏查看

- **最小面（本轮做）**：
  - 子流首部落一条 meta 事件（agent 名/父会话 id/delegationId/description）——
    历史页/搜索可标记「子代理」徽章 + 父会话溯源。
  - task 工具卡（对话流内，结果卡 meta 已带子 sessionId）加「查看过程」点击 →
    复用 `viewSession` 打开子会话只读回放（含运行中委托——回放到已落事件，
    「刷新」重拉看新进展）。
  - 历史页行：子会话带「子代理」徽章（meta 事件驱动），点击同样回放。
- **实时跟随（记档不取本轮）**：子 loop 运行中跨会话订阅推送（UI 需要第二路
  WS 订阅面）——评估为独立增量，回放+手动刷新已覆盖"看实际会话过程"的主诉求。
- **不做**：独立 side pane 双栏（zcode 形态）——我方单会话主区 + 路由回放已可达，
  双栏是布局增量不是能力增量。

### G3. 结果正确回流的四道保证

1. task_wait 主动收割（工具结果直返）；
2. end 期收敛注入（decideTurn 钩子——**模型忘收割也拦得住**）；
3. 报告 12K 截断（防子代理长报告炸父上下文——头尾保留）；
4. 失败/取消同样回流（`<task_report state="failed">` 带错误——父模型可重派）。

### G 的工程量与风险

- 内核：`subagent.ts`（注册表+启动/收割拆分+收敛钩子）+ `task.ts`（background
  参数）+ 3 个新工具文件 + settings/registry 注册——预计 400~500 行含测试；
- UI：task 卡「查看过程」+ 历史页子代理徽章 + meta 事件——小增量；
- 风险点：①注册表并发竞态（await 收敛期间的 task_stop——以注册表单一 Map +
  状态机防重入）；②decideTurn 长阻塞（等待期间父 turn 无法取消？——收敛等待
  挂 ctx.signal，父取消即中止等待并结算）；③子 loop 崩溃孤立（结算 failed 回流，
  孤儿闭合走既有 interrupted 路径）。
