## 第一部分：设置页（左侧 ⚙ 设置里的 19 个小页）

### `[x]` 供应商（就是你现在正在看的这页）

**这页是干什么的**：管理 AI 服务商——你要用哪些 AI 公司的接口、密钥是什么、有哪些模型、默认用哪个。相当于"AI 服务通讯录"。

**照着谁改的**：pi-desktop 的「模型配置」页（你给我截图的那个）。

**现在长什么样**：
- 顶部一张"默认模型"卡：显示当前开机默认用哪个服务哪个模型，右边有**两个下拉框**——先选服务，再选该服务下的模型（第二个下拉会跟着第一个变）。
- 中间"AI 服务"列表：每个服务商一行卡片（圆角、独立一行），左边一个**首字母圆形头像**，名字旁边有小标签（"默认"=开机用它的、"已停用"、"未设密钥"），下面一行小字是网址和模型数量；右边是**开关**（不开机用但保留配置）和 **⋯ 按钮**（点开菜单：编辑 / 本会话切换 / 测试连接 / 上移 / 下移 / 删除）。
- 点"添加服务"或"编辑"弹出**大窗口**（占屏幕 80% 宽，点窗口外面不会关，只能点"取消"或"保存服务"）：
  - 填：名称、接口地址、API 密钥、接口格式（四种协议）。
  - 左栏"该服务的模型"：点**获取列表**会真的去服务商那里拉模型清单回来（勾选想要的）；也可以在最下面手动输入模型 ID 添加。
  - 右栏"模型设置"：每个勾选的模型一张卡，可以单独改它的**接口协议**（同一个网站有的模型走 OpenAI 格式、有的走 Anthropic 格式——按模型单独设）、点**高级**展开设置别名、上下文窗口大小（128k~1M 快捷键）、最大输出、思考等级。
  - 顶部按钮"高级设置"可以加**自定义请求头**（有些中转站需要加特殊头才让用）；"测试连接"会**真的给这个模型发一句"你好"**，收到回复才算通过（通过的模型卡片上会盖"✓ 已实测"章）。

**怎么验收（一步步来）**：
1. 打开这页，看"默认模型"卡：两个下拉，先选服务再选模型，选完下面那行字会不会跟着变。
2. 看服务列表：每行是不是独立卡片、头像、徽标、开关和 ⋯ 都在。
3. 点 ⋯ 菜单：六项都在；点"上移"或"下移"，看行顺序会不会变、列表**会不会消失**（上次你说会消失，修了，重点试）。
4. 点"添加服务"：窗口够不够大；在窗口外点一下鼠标，窗口**不应该**关。
5. 接口格式下拉：应该有 4 项（OpenAI Chat Completions / OpenAI Responses / Anthropic Messages / Google Generative AI）。
6. 真实测一次：填一个你能用的服务商地址和密钥 → 获取列表 → 勾几个模型 → 测试连接 → 看是否显示"✔ 已连接·模型回复：…"。
7. 都没问题 → 打勾。

### `[ ]` 权限档

**怎么验收**：
