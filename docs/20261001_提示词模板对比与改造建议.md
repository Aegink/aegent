# 提示词模板页对比与改造建议（2026-10-01）

> 调研阶段产物（用户规则：先报告后改码）。四轮串行调研：①pi-desktop + cc-switch
> （其 prompts 面板是 pi 模板系统的管理器镜像）；②zcode（命令域最完整的桌面实现）；
> ③opencode（唯一把 MCP prompts 桥接为命令的仓）；④codex / claude-official（命令
> frontmatter 规格权威）/ kimi-code / qwen-code / pi-mono / pideck / grok-build 扫描。
> 全部结论附 file:line（相对各仓库根）。

---

## 0. 结论一句话

参考仓里的「提示词模板」实际是**参数化自定义命令系统**：markdown 文件 +
frontmatter（description / argument-hint）+ `$ARGUMENTS/$1..$N` 参数 + **发送时展开**
（参数打在 `/name` 后面，不是插入后手改）+ 项目/用户双层遮蔽 + 启停开关 + 外部生态
导入。我方现状只有「settings JSON 条目 + 插入时整段替换 + {{var}} 手改」这层皮，
差距主要在参数内核、发送时展开链路、文件化与导入三块。核心闭环（A 参数化 + B 元数据
+ F 补全升级 + E 拦截）侵入度小-中；文件化（C）与导入（D）有技能页/MCP 页同构先例
可抄；执行语义扩展（H）是前沿位。

## 3. 参考仓要点

### 3.1 pi-desktop + cc-switch（参数语法最全 + 管理面工程化）

- **双目录文件存储**：`<workspace>/.pi/prompts/*.md` + `~/.pi/agent/prompts/*.md`，
  项目级遮蔽用户级（`packages/agent-runtime/src/prompt-templates.ts:48-55,90-116`）。
- **参数语法全集**：`$1..$n`、`$@`、`$ARGUMENTS`、`${@:N}`（第 N 起剩余）、
  `${@:N:L}`（N 起取 L 个）；空格/引号分词；缺位补空串；**无占位符时非空参数以空行
  追加**（`:125,139-141,156-161`；测试 `prompt-templates.test.ts:11-63`）。
- **求值时机 = 发送时**（Electron main `agent/prompt` handler 持久化前展开，展开产物
  `content` + 原始调用 `command` 双字段持久化——`apps/desktop/electron/main/ipc/agent-ipc.ts:436-480`；
  类型 `SlashExpansion` `messages.ts:99-104`）→ reseed/regenerate 与模型所见一致。
- **transcript chip**：消息行渲染 `command` 原文等宽 chip，hover 显示展开全文
  （`MessageRow.tsx:217-231`）。
- **五源合并 slash 菜单**：template + builtin + plugin + extension + skill，去重
  first-wins，template 排最前（`composer-ipc.ts:76-117`）。
- **三分派 fail-closed**：dispatch（本地执行）/ prompt（模板走展开）/ blocked（命令源
  读取失败拒发，防控制命令降级为模型文本）（`slash-dispatch.ts:39-64`）。
- **IME 适配**：空草稿首字符 `、` 自动重写为 `/` 开命令菜单（ADR 0231，
  `composer-trigger.ts:49-62`）；IME 组合期菜单冻结。
- **cc-switch 管理面**（`src/components/prompts/PiNativePromptResources.tsx`，802 行）：
  slug 校验（保留字符/Windows 保留名/≤128B）、重名即时检测、description 与 frontmatter
  双向同步、可折叠语法帮助（frontmatter + `$1 ${@:2} $ARGUMENTS` 示例代码块
  `:530-567`）、revision = SHA-256 乐观锁防外部编辑冲突、重命名原子回滚
  （`pi_prompt_files.rs:206-292`）。
- **一键润色**（`prompt-enhancement.ts`）：`{{draft}}` 单变量、模板 8000 上限、
  split/join 防 `$&` 注入、固定 system prompt 仅 user 模板可覆盖、「插入 {{draft}}」
  光标位插入、缺占位符静默回退默认、编辑回默认 = 清除覆盖、成功后撤销恢复原文。
- **热更新语义提示**：修改后 toast「请运行 /reload」。

### 3.2 zcode（桌面管理页 + 外部导入的标杆）

- **存储**：用户级 `~/.zcode/commands` + 项目级 `<workspace>/.zcode/commands`，md +
  frontmatter 只认 `description`/`argument-hint`，**未知 frontmatter 键保留不丢**
  （`commandFileParser.ts:100-143`）；子目录 = 命名空间（`dir/sub/cmd.md` →
  `/dir/sub/cmd`，`commandsService.ts:475-487`）；workspace > user、`.zcode` > `.agents`
  遮蔽（`:982-1004`）。
- **启停**：config 覆盖表按绝对路径记 `enable=false`，**不改文件**；改名自动迁移禁用
  状态防复活（`:112-155,675-688`）。
- **参数**：`$ARGUMENTS` + `$1..$N`，shell 风格引号/转义切分（`contracts/src/commands/index.ts:191-232`）；
  无占位符时自动追加 `\n\nUser arguments:` 兜底（`:152-154`）。
- **发送时展开在 agent 侧**：面板选中只插入原子 `/name` mention chip + 尾随空格，参数
  用户续打（`SlashCommandPlugin.tsx:246-310`）；agent 侧统一展开 + 包装头溯源
  （`custom-command-prompt.ts:31-89`）。
- **管理页**（`CommandsSection.tsx` + `CommandForm.tsx`）：本地命令组 + 按插件分组、
  name 编辑态锁定、Scope 菜单（User/各 workspace）、argument-hint 字段、保存即热同步
  `/` 面板目录（`pluginSlashCommandRefresh.ts:31-56`）。
- **外部导入**：13 家外部 agent 命令目录映射（claude/codex/opencode/qwen/roo/…）+
  symlink/copy 双模式 + 勾选弹窗（`settingsSyncService.ts:183-249,1900-1985`）。
- **补全面板**：三段分组（Commands/Skills/Subagents）、模糊三档评分 + description 加权
  （`promptInputTriggers.ts:52-111`）、↑↓/Enter/Tab/Esc、Esc 同 token 防重弹。
- **防护**：保留名注册表 + 禁用名单读文件前门禁（`slash-command-surface.ts:19-34`）、
  100KB 截断、扫描深度 12、9 个诊断码分级。
- **`!`shell`` 展开**：30s 超时、128KB 上限、错误含 stderr 预览、无 executionPort 显式
  报不支持（`custom-command-shell-expansion.ts`）。

### 3.3 opencode（执行语义最富 + MCP prompts 桥接独一份）

- **双存储**：`command(s)/**/*.md`（两种拼写都认）+ `opencode.json` 的 `command` 段，
  mergeDeep 后者覆盖；作用域链全局目录 + 项目目录链（`config/command.ts:15`、
  `config.ts:473`、`paths.ts:23-41`）。
- **frontmatter 字段**：`template/description/agent/model（provider/model#variant）/variant/subtask`
  （`core/src/v1/config/command.ts:5-12`）；解析失败**硬报错带文件路径**（反面：宽松
  回退也有——`core/src/config/markdown.ts:20-36` 先 sanitize Claude 风格未引号冒号）。
- **执行链**（`session/prompt.ts:1356-1481`）：发送时参数替换（**末位占位符吞掉剩余
  全部参数**，`:1376-1389`）→ `!`shell`` 注入（**无超时无截断——反面教材**，`:1397-1408`）→

- **MCP prompts 桥接**：每个已连 server 的 prompt 注册为命令，名 =
  `server:prompt` 命名空间，模板懒 Promise，参数映射 `$1..$N`（`command/index.ts:105-132`）。
- **内置模板命令** `/init` `/review`：代码内嵌模板正文，**可被用户同名覆盖**
  （`:70-88`；文档 `commands.mdx:319-323`）。
- **UI**：来源徽章（skill/mcp/custom，`slash-popover.tsx:335-356`）、选中插入 `/name `
  等参数、错误提示附可用命令清单（`prompt.ts:1363-1369`）。

  allowed-tools（Bash(git:*) 前缀过滤）/ model / argument-hint / disable-model-invocation`

- **kimi-code**：ACP 侧仅内置 6 命令 + skill 投影（裸名/`skill:` 前缀、内置撞名优先），

## 4. 改造方案（A~J）

> 分组按依赖排：A 是灵魂（参数化+发送时展开），B/F/E 是 A 的直接配套，D 吃生态
> （依赖 C 的文件化或以条目导入），C 是存储形态决策，G/H/I 是扩展位。

### A 参数化内核 + 发送时展开【核心 · 中】

- `PromptEntry` += `argumentHint?`；展开内核支持 `$ARGUMENTS` + `$1..$N`（引号切分、
  缺位补空串、无占位符时参数空行追加——四仓族交集语义，语法仲裁以 pi-mono
  `substituteArgs` 为准）。
- **发送时展开**：输入区选中模板不再整段插入，改为插入 `/name `（hint 以占位提示），
  参数续打回车后由 host 展开再转发（展开点候选：host 转发面——与 settings 同进程零新
  增 IPC；实施时按消息链路定，pi 在 Electron main、zcode 在 agent 侧、opencode 在
  server 端）。展开产物持久化 `{command, content}` 双字段。
- transcript chip：用户消息渲染原始调用 chip + hover 展开全文（pi 形态）。
- 现有 `{{var}}` 插入流**保留**：无参模板维持整段插入手改（双模式并存——zcode 也是
  本地执行/展开两轨并存）。

### B 元数据与管理面加固【小】

- argument-hint 字段（列表行 + 补全行内展示）；slug 校验（空白/保留字符/Windows 保留
  名/≤128B）+ 重名即时检测；可折叠「模板语法」帮助面板（{{var}} + $ARGUMENTS + $1
  示例代码块）；状态行（共 N 个）；description 缺省回退正文首行截 60 字符。

### C 文件化存储【中-大 · 架构决策点】

- 迁移 settings `prompts` 段 → `<workspaceRoot>/.zcode/prompts/*.md`（frontmatter
  `description/argument-hint`，未知键保留；技能页 `.zcode/skills` 同构先例）。
- 用户级目录 + 子目录命名空间 + 项目>用户遮蔽（zcode 形态）。
- 外部编辑感知：设置页打开/聚焦时重扫；诊断（坏 frontmatter/超限）。
- settings 段一次性迁移 + 读取兼容一个版本；settings-transfer 导出格式同步演进。
- 【备选 C2】不文件化，导入走条目化——失去生态文件共享与外部编辑器红利，不推荐。

### D 外部命令导入【中 · 用户既有心智——MCP/技能页同款】

- 扫描源（一层目录）：`.claude/commands`、`~/.claude/commands`、`.opencode/command(s)`、
  `~/.config/opencode/command(s)`、`.zcode/commands`、`~/.zcode/commands`、`.pi/prompts`、
  `~/.pi/agent/prompts`、`.qwen/commands`、`.agents/commands`。
- frontmatter 宽松解析（中文未引号 description 兼容——zcode/qwen 踩过的坑）；勾选导入
  （文件化 = 复制 md 进我方根；同名 skip + 来源徽章 + 一层/递归开关）。
- host 新 op（`prompts-import-scan/apply`），护栏同技能导入（slug/同名 skip/源路径限源表内）。

### E 启停开关 + 拦截与诊断【小】

- 启停开关不改正文（disabled 名单；文件化后 = settings 覆盖表或 `.zcode` 白名单，
  改名自动迁移——zcode 防复活语义）；保留名表（`/cancel /find /search /history
  /settings /help` 等本地命令 + `/compact /init` 类未来保留名）。
- **未知命令本地拦截**：`/xxx` 无候选时本地报错不进模型（codex/kimi 语义；含展开失败
  拒发 fail-closed）。
- 诊断行（重名/坏 frontmatter/超限，技能页诊断折叠形态复用）。

### F 补全交互升级【中】

- 模糊三档评分（前缀 < 子串 < fuzzy 子序列，description 加权——zcode）+ 分组分段
  （命令/工具/技能/模板，icon 与组头）+ argument-hint 行内展示 + 来源徽章。
- 选中行为分型：无参模板 = 整段插入（现状 {{var}} 手改流）；有参模板 = 插入 `/name `
  等参数（hint 占位提示）。
- Esc 同 token 防重弹；IME `、`→`/` 适配（pi ADR 0231）。

### G 内置模板命令【小-中】

- `/init` 式内置 prompt 模板（生成/改进 AGENTS.md 项目说明），代码内嵌正文，用户同名
  可覆盖（opencode 语义）；来源徽章「内置」。

### H 执行语义扩展【大 · 前沿位】

- frontmatter `model`（命令级模型覆盖，链 = 命令 > 会话）；`agent`（以指定子代理执行
  ——subtask 转 TaskTool，与刚落地的子代理域同构；opencode `prompt.ts:1439-1458`）；
  `disable-model-invocation`（模型程序化调用开关）。
- `!`shell`` 前置执行注入（**必须带**：超时 + 输出上限 + 确认流〔qwen
  `ConfirmationRequiredError` 先例〕+ 沙箱档联动；opencode 无门控是反面教材）。
- `@file` 注入（调用时读文件进上下文，目录/`~/` 支持、去重）。
- **MCP prompts 桥接**（差异化——opencode 独有，zcode 反证空白）：MCP 域加
