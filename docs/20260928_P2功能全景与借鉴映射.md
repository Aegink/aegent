## 二、全景分组（48 条按域归并）

- **会话与生命周期（Q/E/M 族，15a）**：保留-清理-归档三件策略一致性（同一 RETENTION_POLICY 消费链、归档唯一入口、清理判龄幂等）；内存态（M4）× 磁盘态（Q4）分域互不调用；Q2 检索只读零落流；E6 同一抽象（fork 事件即树事实，`findLast` 血统语义实测钉死）；E9 引用是流内指针 + 读取时现算有界快照（≤3 引用 / 4000 字符 / 不可信警示）。
- **权限与判官（C 族，15b）**：判官只是 abstain→allow/deny 的修正路径（deny 后无裁决权）；匹配在参数校验后；结构化拒绝与既有拒绝逐字节兼容。C56 接口面（批次 9）→ C42 本体兑现的"先接口后实现"两段式。
- **插件与远程后端（I/H/D 族，15c）**：受限能力 token（属性闭集 + 内核句柄零暴露 + 无 ctx）；不可信边界三件（trust 恒 untrusted / 注册缺省全拒 / 执行往返 deadline）；治理建议非强制（I11 ≠ 策略）；两后端同语义（进程内 fork + ACP）；SSH 命令行包装零新依赖。
- **端与自动化（S/K/N/P 族，15d）**：job 底座三消费方（S1/M11/S2 同一 JobRegistry）；S4 最强审批三层（unattended 恒拒先于审批）；IM 抢约派发（发消息 = 声明控制端，N7 单 holder 兼容）；N5 分型是 wire 载荷非事件。
- **观测与工程纪律（T/O/F/L/J 族，15e）**：复杂度断言是形状不是耗时（比值上界 4 + min-of-3）；测试基建受治理（keyless 两条 + 升降级规则 + 十场景规约）；fixture 三约定（错误 fail-loud / 忽略显式 / 未知拒绝——比 codex 更严）；两级压缩判据 = 事实能否从流重算（micro 确定性投影零事件 vs full 不可重算落流）；known-diffs 18 蓝本域只追加不替换；审计报表是记录流的投影（零除防呆 null 不 NaN）。

## 六、P2 的三条方法沉淀（接 P0/P1 的九条）

10. **"事件能否从流重算"是词汇表单向门的操作判据**：P2 三处零扩展定形（E6 深度 / M4 回收 / F19 microcompact）共用同一判据——可重算的派生事实与确定性投影不落流；不可重算的决策与外部事实（摘要内容、人反馈、取代关系）才走立案。判据从"语义辩论"收敛为"可执行检查"，是 Q9 纪律三次演练后的成熟形态。
11. **核对关闭卡的价值在留下判据而非代码**（T4/J21 前半/J25/L10 先例族）：T4 的四面核对（检查器强制/负例/空集/无内联豁免）把"豁免必须带理由"从需求变成可审计的现状陈述；J21 的"先核对"避免了第二份 usage 聚合——核对卡是纪律的复利。
12. **测试政策成文后，基建的"进出"有法可依**（O28）：keyless 两条 + 升降级规则 + 十场景"用哪个件/禁止的替代做法"——散件回潮（手写期望数组、现场拼坏响应）从风格问题升级为可指认的违规；渐进接入（event-pump 哨兵形态）让 191 文件的全量切换不需要一次性摊派。
