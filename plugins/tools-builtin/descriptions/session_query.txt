Search recorded session history with structured filters (session id prefix, time range, event types, content substring). All filters are ANDed; results are ordered newest-first and paginated (limit/offset). Returns one summary line per hit (session id, seq, type, timestamp) plus a short excerpt when a content filter is given. Persisted sessions only — archived sessions are reported by id but their data lives in the archive (main store no longer holds it).
Search runs as SQL over the event store; it never loads full sessions into memory. Read-only: it does not append events or modify state.
