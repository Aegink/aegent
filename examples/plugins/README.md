# aegent 示例插件（T-P3-148 W——万物可插件的活文档）

三个示例演示插件系统的三种消费路径（全部走与第三方完全相同的清单/装载/审批通道）：

- **hello-view**：视图 + 命令贡献。安装方式 = 插件中心 → 安装插件 → 进程内 →
  装载源填本目录绝对路径。
- **echo-tool**：工具 + 设置 + 订阅贡献（SDK 受限能力 token 面）。
- **marketplace.json**（本目录）：本地市场源示例。插件中心 → 市场 → 添加
  市场源 → 填本目录绝对路径 → 浏览安装前两个示例。

创建自己的插件：插件中心 → 创建 → 四模板（视图/智能体工具/技能包/全部能力），
或让 agent 调用 `plugin_create` 工具生成。
