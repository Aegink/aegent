Define (activate) a dynamic in-process plugin from inline ESM source code. The code must default-export an AegentPlugin object ({ onActivate(caps), onEvent?, onDispose? }); use caps.registerTool to register tools and caps.subscribe for session events. The plugin is ephemeral: it disappears on session restart and is never persisted to settings. Code runs in-process with host-level privileges (not sandboxed) - never activate code from untrusted sources. Prefer plugin_create for persistent plugins.
