Runs a PowerShell command and returns its stdout/stderr with the exit code. Use this tool when you need Windows-native operations (registry via PowerShell provider, Windows services, WMI/CIM queries, PowerShell-only cmdlets). The command runs in a fresh, non-interactive PowerShell process; output truncation and the same redirection path guards as bash apply. Note: PowerShell exit codes follow host semantics, and prefer bash for POSIX-style pipelines.
