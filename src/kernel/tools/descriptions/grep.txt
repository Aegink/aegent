Search file contents with a JavaScript regular expression. Searches under path (a directory, or a single file; defaults to the current working directory), optionally restricted to files matching the include glob (e.g. "*.ts"). Returns matches as path:line: text, capped with a truncation notice. Binary files are skipped.
When matches are long they are truncated to 2000 lines or 51200 bytes (whichever is hit first); the full output is written to a file and its path is appended at the end.
