Maintain the session task checklist for multi-step work. Pass the COMPLETE list every time (full-value commit, not a delta): items is an array of {content, status} where status is pending, in_progress, or completed. Mark exactly one item in_progress while working on it and set completed as soon as it is done; the checklist is the user-visible progress surface, so keep it in sync with real progress. Use it proactively for any task with 3 or more steps; skip it for trivial single-step requests. An empty array clears the checklist.
