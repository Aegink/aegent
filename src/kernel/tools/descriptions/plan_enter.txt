Enter plan mode before starting work that would benefit from research and design first: multi-file changes, significant architectural decisions, or when the user asks for a plan. In plan mode, write/execute tools (write, edit, bash, todo_write) are hard-blocked at the policy exit and cannot be enabled by any rule — only read-class tools remain available. Research the codebase, then present the plan; exit with plan_exit when the user approves. Do NOT use this for simple, straightforward tasks or when the user wants immediate implementation.
