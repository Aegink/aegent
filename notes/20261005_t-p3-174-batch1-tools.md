## 步骤与观察
1. **调研**（三 agent 串行，全部源码级）：codex exec_command 是 yield 时间片式（无显式 run_in_background——我方按批次卡走 boolean+task_id 显式面）；pi-desktop capture/spill 双层预算（512KB/96KB、stdout 保头 stderr 保尾、单行 16384 字符、spill 先于截断）；zcode webfetch 缓存（Map 保序 LRU+TTL 15min+总量 50MB）；qwen blob→raw（host 精确匹配+build 期重写）与 notebook_edit（手写 JSON+格式保真+执行事实重置）。
2. **实施九件套**：①env 扩展可选 `execFile`/`spawnBackground` 能力（D4 纪律——进程词汇只在 env.ts，证伪命令保持 0 行）；②BackgroundShellRegistry（64 容量+已结束驱逐+dispose 全杀，opencode 非持久同款）；③bash/pwsh `run_in_background`；④task_output（轮询 wait_seconds/kill/task_id 清单自纠）；⑤shell-output.ts 双层预算格式化（stdout 96KB/4000 行保头+stderr 保尾+单行 16384 裁+spill 落 `<workspace>/.aegent/scratch/tool-output/`（Q13 标记首行）+尾部"完整输出已存至 X（N KB）"）；⑥registry boundOutput 尊重 `meta.outputBounded`（shell 结果跳过 50KB 通用截断——防双截断双 spill）；⑦view_image（附件链注入：字节进 AttachmentStore+loop 在 tool/result 后追加 injected user/message，wire 序 assistant(tool_calls)→tool→user(image)）；⑧get_context_remaining（assembly PressureMonitor 只读投影——codex 同款"只报剩余"）；⑨webfetch 增强（15min 缓存/blob→raw/HTTPS 升级+回退/同源重定向≤5 跳/跨域返回指引不跟随）+grep rg 快路径（env.execFile+--json+8MB cap+退出码 0/1 之外无缝回退内置+JS lookahead 直接回退）+save_memory（追加 ~/.aegent/memory/MEMORY.md——C2 挂点）+notebook_edit（replace/insert/delete+cell-N 回退+歧义报错+格式保真）。
3. **测试**：BUILTIN_TOOL_NAMES 25→30、四处基线同步（plan-mode/todo/causal/builtin）；新 batch1-tools.test 36 用例全绿；全量 2112 绿 0 失败；tsc 0 错。
4. **真实模型轮两路**（权威验收）：A 路 bash 后台启动→task_output 轮询（bg-live-2 输出/status/elapsed 全实）→get_context_remaining（200000/7801/192199 真实计量）→save_memory（落盘+内容对）；B 路 view_image（红 png 注入成功）→notebook_edit（c1 replace+执行事实重置）→webfetch（GitHub raw 真抓）→grep（真实命中）。**0 错误**。
5. **真实轮暴露两个设计缺陷（当场修复）**：
   - **auto 档（danger-full-access 沙箱装配）下 run_in_background 恒被拒**——生产默认路径后台功能不可用。修=沙箱在场时仅当有效档是 danger-full-access 允许 env 后台启动（该档下 local 后端本身就是 env 直通，语义等价）；受限档仍 fail-closed。
   - **生产装配 attachmentStore 从未注入**——附件链（用户图片上传+view_image）全缺位。修=child 有 --db 时装配 LocalFileAttachmentStore（`<库目录>/attachments`），loop resolver 与 view_image 同一实例。
6. **env kill 的 Windows 深坑**：close 事件在 taskkill 杀树后可能拖到孙进程自然退出（实测 sleep 30 → close 晚 30s——管道句柄被持有）——settle 挂 **exit** 而非 close（exit 1.9s 即触发），kill 后终态快照恒即时。
7. 便携重编（build:single 171.6MB runtime+tauri exe）+ 冒烟 + commit/push + 记档。
